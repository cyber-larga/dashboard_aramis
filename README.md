Présentation vidéo : https://www.youtube.com/watch?v=4Q-OoNSKUWk
(également intégrée directement dans l'application)

Conception d'une application interactive pour analyser les ventes automobiles et profiler la clientèle pour un intervenant Aramis Auto (réaliser avec IA).
Développement Assisté : Prototypage rapide de l'interface R Shiny multi-onglets assisté par des outils d'IA générative (Antigravity).
Statistiques (ACP & Régression) : Application de l'ACP et de la régression linéaire pour analyser les données et comprendre les dynamiques de ventes.
Data Visualistion : Visualisation dynamique des profils acheteurs et des types de véhicules vendus.
